Contoh hasil: integrasi dan kontrak API sistem konsultasi UKPBJ

1 · Daftar integrasi
Dari → ke Data yang dikirim Kapan dikirim Jika gagal
Portal publik → Konsultasi PBJ konsultasi_id, tanggal Tiap 5 menit Tampilkan jadwal terakhir
Konsultasi PBJ → Email service Email pemohon, pokja, jam Saat konsultasi disetujui Tandai "gagal kirim", coba ulang
Konsultasi PBJ → Identity provider Token login Saat pegawai login Minta pegawai login ulang
2 · Satu kontrak API: ambil jadwal konsultasi
GET /api/v1/konsultasi/K01/jadwal
Authorization: Bearer <token>
200 OK
{ "konsultasi_id": "K01", "jadwal": [ { "mulai": "09:00", "status": "DISETUJUI" } ] }
Error yang disepakati
401 UNAUTHORIZED
Token tidak ada atau tidak valid.
404 KONSULTASI_TIDAK_ADA
Kode konsultasi tidak ditemukan.
